How to use this tracker

1. Get the MFG PDF

  1. Log in to MFG and open Moulding Report.
  2. Wait for the report to finish loading.
  3. Press ⌘ Command + P and print to PDF.
  4. Save it as MFG + the date (for example, MFG 2026-10-23.pdf).

2. Get the Order Entry report

  1. Open Order Entry.
  2. Go to Reports → Summery Report → Moulding Schedule.
  3. Click Run Report.
  4. Save the generated report as a PDF for upload below.

3. Make your lists

  1. Choose both PDFs, then click Generate.
  2. Select items and choose To Run or To Pull. Check stock warnings before deciding.
  3. Click Print Moulder Report to print all To Run items on portrait paper, from any tab. Each moulding number gets its own request page, including stock profiles. Stock run quantities use the preset batch targets. One full-scale drawing per moulding is included in the drawing section. Print any missing drawings manually. Use 100% / Actual Size, margins None, and turn headers/footers off. Check the printed 1-inch scale line. After printing, choose Printed — Mark Sent & Save.
  4. Use To Pull to view stock work.

Changes save to the shared tracker. Crossed-off MFG rows appear under Already Run and stay off new requests. Items removed from the MFG schedule retain their history.

Due within 6 workdays, including overdue work.
